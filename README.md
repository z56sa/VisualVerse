# ⚡ FeedPulse - بوت تجميع وتلخيص الأخبار التلقائي بالذكاء الاصطناعي

بوت ديسكورد احترافي يقوم بمتابعة خلاصات الأخبار (RSS Feeds) تلقائياً، وتلخيصها وترجمتها بالذكاء الاصطناعي إلى العربية، ونشرها في رومات ديسكورد بتنسيق Embed سينمائي جذاب.

---

## ✨ المميزات:
1. **نشر تلقائي فوري للأخبار**: يفحص روابط الـ RSS بشكل دوري وينشر الأخبار الجديدة فور صدورها دون أي تكرار.
2. **تلخيص وترجمة بالذكاء الاصطناعي (Gemini AI)**: تحويل الخبر الإنجليزي المعقد إلى عنوان عربي جذاب وملخص من 3 نقاط سهلة القراءة.
3. **أمر `/setup-feed [channel] [url]`**: لتحديد روم النشر وإضافة أي رابط RSS تريده (ألعاب، أنمي، تكنولوجيا، سيارات، اقتصاد).
4. **أمر `/latest-news [category]`**: طلب أحدث 3 أخبار فوراً في الشات ملخصة بالذكاء الاصطناعي.
5. **أمر `/daily-recap`**: توليد حصاد ونشرة إخبارية ذكية تلخص أهم أحداث اليوم في ثوانٍ.
6. **جاهز 100% للاستضافة على Render**: يحتوي على خادم فحص صحة (Health Check Server) مدمج.

---

## 🚀 المتغيرات المطلوبة في Render (`Environment Variables`):

| المفتاح (KEY) | الوصف |
|---|---|
| `DISCORD_TOKEN` | توكن البوت من Discord Developer Portal |
| `CLIENT_ID` | Application ID من ديسكورد |
| `GEMINI_API_KEY` | مفتاح Google Gemini المجاني من [aistudio.google.com](https://aistudio.google.com/) |
| `GUILD_ID` | *(اختياري)* لتسجيل الأوامر فورياً في سيرفر تجريبي |
| `PORT` | يتم تعيينه تلقائياً بواسطة Render (3000) |
